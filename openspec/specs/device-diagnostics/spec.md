## ADDED Requirements

### Requirement: getPreviousRebootInfo JSON-RPC method
The `DeviceDiagnostics` plugin SHALL expose `getPreviousRebootInfo` as a JSON-RPC method under the `org.rdk.DeviceDiagnostics` callsign.

The request SHALL require no parameters:
```json
{
    "jsonrpc": "2.0",
    "id": 42,
    "method": "org.rdk.DeviceDiagnostics.getPreviousRebootInfo"
}
```

The response SHALL conform to:
```json
{
    "jsonrpc": "2.0",
    "id": 42,
    "result": {
        "rebootInfo": {
            "timestamp": "20200128083540",
            "source": "SystemPlugin",
            "reason": "FIRMWARE_FAILURE",
            "customReason": "API Validation",
            "otherReason": "API Validation",
            "lastHardPowerReset": "Tue Jan 28 08:22:22 UTC 2020"
        },
        "success": true
    }
}
```

The JSON-RPC stub SHALL be auto-generated by `Exchange::JDeviceDiagnostics` from the `@json`-annotated `GetPreviousRebootInfo` method in `IDeviceDiagnostics.h`. No manual `registerMethod` call SHALL be used.

#### Scenario: Successful JSON-RPC call after device reboot
- **WHEN** the device has rebooted and `/opt/secure/reboot/previousreboot.info` is populated
- **AND** the app sends `{"method": "org.rdk.DeviceDiagnostics.getPreviousRebootInfo"}`
- **THEN** the plugin SHALL return a JSON-RPC 2.0 response with `result.rebootInfo` containing all six fields and `result.success = true`

#### Scenario: JSON-RPC call on first boot (no prior reboot)
- **WHEN** the device has never rebooted and `/opt/secure/reboot/previousreboot.info` does not exist
- **AND** the app sends `{"method": "org.rdk.DeviceDiagnostics.getPreviousRebootInfo"}`
- **THEN** the plugin SHALL return a JSON-RPC 2.0 response with `result.success = false`

### Requirement: GetPreviousRebootInfo COM-RPC method on IDeviceDiagnostics
The `Exchange::IDeviceDiagnostics` interface SHALL declare:

```cpp
Core::hresult GetPreviousRebootInfo(RebootInfo& rebootInfo /* @out */, bool& success /* @out */);
```

The `RebootInfo` struct (already defined in `IDeviceDiagnostics.h`) SHALL be used without modification. It carries the fields: `timestamp`, `source`, `reason`, `customReason`, `otherReason`, `lastHardPowerReset`.

The method SHALL return `Core::ERROR_NONE` on success and `Core::ERROR_GENERAL` on failure.

#### Scenario: COM-RPC method registered successfully on plugin initialisation
- **WHEN** the `DeviceDiagnostics` plugin shell calls `Exchange::JDeviceDiagnostics::Register(*this, _deviceDiagnostics)`
- **THEN** the `getPreviousRebootInfo` JSON-RPC stub SHALL be available without additional registration steps

#### Scenario: COM-RPC method returns error on file absence
- **WHEN** a COM-RPC caller invokes `GetPreviousRebootInfo(rebootInfo, success)`
- **AND** `/opt/secure/reboot/previousreboot.info` does not exist
- **THEN** `success` SHALL be `false`
- **AND** the method SHALL return `Core::ERROR_GENERAL`

## MODIFIED Requirements

### Requirement: External file dependencies
The `DeviceDiagnostics` plugin relies on the following runtime filesystem paths:

| Path | Access | Purpose |
|---|---|---|
| `/opt/logs/rdk_milestones.log` | Read | Source for `getMilestones` |
| `/opt/secure/reboot/previousreboot.info` | Read | Source for `getPreviousRebootInfo` — `timestamp`, `source`, `reason`, `customReason`, `otherReason` |
| `/opt/secure/reboot/hardpower.info` | Read | Source for `getPreviousRebootInfo` — `lastHardPowerReset` |

These files SHALL be read synchronously on each invocation. The plugin SHALL NOT cache their contents across calls.

#### Scenario: Previous reboot info file parsed correctly
- **WHEN** `/opt/secure/reboot/previousreboot.info` contains key=value lines
- **THEN** the implementation SHALL map `reboot_timestamp` → `timestamp`, `reboot_source` → `source`, `reboot_reason` → `reason`, `reboot_custom_reason` → `customReason`, `reboot_other_reason` → `otherReason`

#### Scenario: Hard power reset file parsed correctly
- **WHEN** `/opt/secure/reboot/hardpower.info` exists and contains a single timestamp line
- **THEN** the implementation SHALL trim whitespace and assign the line to `lastHardPowerReset`
